# Disaster Tabletop Simulator

2026年度の院内災害訓練に先立って実施する、机上訓練用Webアプリです。

要件定義に基づく操作画面の第一版を開発中です。確定仕様と受入条件は
[docs/requirements.md](docs/requirements.md)を参照してください。

## 基本方針

- 病院の実際の間取りを再現せず、患者の流れが把握しやすい模式図を使う
- 患者役が同行する区間と、電話連絡後の想定上の移動を明確に分ける
- 災害発生前の病床・手術室占有状況を変えて難易度を調整する
- 2026年度50症例を再現しつつ、将来は別シナリオも読み込めるようにする
- 初版は1台の進行役PCと外部モニターで、通信なしでも運用できるPWAとする

## 現在操作できる機能

- 2026年度50症例の時刻順投入
- 模式的な病院フローマップと患者コマ
- ER重症4床、中等症7床、ICU16床、EU30床、手術室の容量表示
- 軽症ゾーンの二次トリアージ、待合、診察室4室
- 患者役「実動」と「想定のみ」の切替
- 軽症ゾーン・救外ゾーン間の3分搬送
- 2倍速の進行時計、時刻到達時の自動来院、一時停止、早送り
- 症例概要、所見、バイタル、検査、治療、追加イベント等の右サイドバー表示
- 進行役画面と投映画面の切替

## ローカル起動

```powershell
pnpm install
pnpm run dev
```

本番用ファイルは `pnpm run build` で `dist` フォルダへ生成します。
